# Product Rules

## Rule 1 — Mobile First

Every feature must work well on phone screens first.

## Rule 2 — Photo First

The product photo is the main content.

Text supports the photo, not the other way around.

## Rule 3 — Uprank Is Not a Like

Uprank must feel like it contributes to rankings.

Use:

```txt
▲ Uprank
```

Do not use:

```txt
Heart like as the primary action
```

## Rule 4 — Cafe and Product Data Must Stay Clean

Avoid messy duplicates.

Users can suggest cafes/products, but official records should be approved.

## Rule 5 — Product Ranking Is the Differentiator

CafeRank should not become just another photo app.

Every major screen should connect back to product ranking/discovery.

## Rule 6 — Do Not Overbuild Early

MVP should focus on:

```txt
Posts
Upranks
Comments
Cafe profiles
Cafe menus
Rankings
```

## Rule 7 — Cafes Are the Business Customer

Users should be free.

Cafes should pay for:

```txt
Verification
Profile management
Analytics
Promotions
Featured placement
```

## Rule 8 — Keep Posting Fast

Creating a post should not feel like filling out a long form.

## Rule 9 — Empty States Should Push Creation

Examples:

```txt
No posts yet → Create Post
No menu yet → Suggest Product
No rankings yet → Uprank products
```

## Rule 10 — Rankings Need Trust

Ranking abuse must be controlled with:

```txt
Login required
One uprank per user/post
Moderation
Rate limits
Admin tools
```
