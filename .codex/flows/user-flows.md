# User Flows

## New User Flow

```txt
Open app
Browse public feed or explore
Sign up
Create profile
Follow users/cafes
Post or uprank
```

## Create Post Flow

```txt
Tap Create
Upload photo
Select cafe
Select product
Add rating
Write caption
Submit post
Post appears in feed
Post appears in cafe profile User Posts tab
Post contributes to product ranking
```

## Uprank Flow

```txt
See post
Tap ▲ Uprank
Uprank count increases
Button becomes active
Product score updates
Post/product can rise in ranking
```

## Comment Flow

```txt
Open post
Tap comment
Write comment
Submit
Comment appears in thread
Comment count updates
```

## Cafe Discovery Flow

```txt
Open Explore
Search cafe/product
Open cafe profile
View User Posts
Switch to Cafe Menu
Open product
Read posts/comments
Save product or visit cafe
```

## Product Discovery Flow

```txt
Open Rankings
Choose category
Tap ranked product
View product detail
View related posts
Open cafe profile
```

## Cafe Owner Flow

```txt
Find cafe page
Request claim
Admin verifies
Cafe owner edits profile
Cafe owner manages menu
Cafe owner views analytics
Cafe owner runs promo
```
