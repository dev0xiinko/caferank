# CafeRank Codex

This `.codex/` folder is the project knowledge base for **CafeRank**.

CafeRank is a mobile-first social ranking app for cafes and cafe products. It works like Instagram, but instead of likes, users **Uprank** cafe products and posts.

## Core Product Idea

> CafeRank helps people discover the most upranked cafe products near them.

Users can:

- Create an account
- Create posts about cafe products
- Upload cafe/product photos
- Uprank posts
- Comment on posts
- Browse cafe profiles
- View cafe menus
- Discover ranked cafe products

Cafes can eventually:

- Claim their profile
- Manage menu items
- View analytics
- Run promos
- Pay for featured placement

## MVP Priority

Build in this order:

1. Authentication
2. User profile
3. Home feed
4. Create post
5. Image upload
6. Uprank system
7. Comments
8. Cafe profile
9. Cafe menu tab
10. Rankings page
11. Admin approval for cafes/products

## Product Rule

The app must always feel:

```txt
Mobile-first
Photo-first
Social
Cafe-focused
Ranking-driven
```
