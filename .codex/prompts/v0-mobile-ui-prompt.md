# v0.dev Mobile UI Prompt

Use this prompt to generate the first CafeRank mobile-first UI prototype.

```txt
Create a mobile-first UI prototype for a social cafe ranking app called CafeRank.

The app should feel like Instagram but for cafes and cafe products. It should be designed primarily for phones with a sticky bottom navigation, photo-first layouts, and thumb-friendly buttons.

Core concept:
Users post cafe products such as Spanish Latte from Espresso Bay. Instead of likes, the app uses an “Uprank” action with an up-arrow icon. Users can uprank posts, comment, and discover ranked cafe products.

Design style:
- Mobile-first
- Warm cafe-inspired palette
- Cream background
- White cards
- Espresso brown text
- Caramel accent
- Rounded corners
- Clean startup aesthetic
- Large product photos
- Minimal clutter

Create these screens:

1. Home Feed
- Instagram-style vertical feed
- Full-width product photos
- Avatar, username, cafe name, product name
- “▲ Uprank” button instead of like
- Comment and save buttons
- Rating, caption, comment preview

2. Cafe Profile
- Instagram-style cafe profile
- Cover photo, logo, cafe name, handle, location
- Stats: posts, rating, rank
- Buttons: Follow and Directions
- Tabs: User Posts and Cafe Menu
- User Posts tab: 3-column photo grid
- Cafe Menu tab: 2-column product grid with photo, name, price, rating, and upranks

3. Create Post
- Upload photo
- Search/select cafe
- Search/select product
- Add rating
- Add caption
- Post button
- Make the form thumb-friendly

4. Rankings
- Mobile list of ranked products
- Horizontal filter chips
- Ranking rows with rank number, product thumbnail, product name, cafe name, rating, and uprank count

5. User Profile
- Avatar, username, bio, stats
- Tabs: Posts, Upranked, Saved
- 3-column photo grid

6. Bottom Navigation
- Home, Explore, Create, Rankings, Profile
- Sticky bottom nav
- Create button should be emphasized

Use mock data and make it look like a polished mobile app.
```
