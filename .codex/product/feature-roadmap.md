# Feature Roadmap

## Phase 1 — Community MVP

Goal: prove that users will post and uprank cafe products.

Features:

```txt
Auth
User profile
Create post
Feed
Uprank
Comments
Cafe profile
Cafe menu tab
Rankings page
```

## Phase 2 — Discovery

Goal: make CafeRank useful for finding cafes/products.

Features:

```txt
Explore page
Search cafes
Search products
Category filters
Location filters
Saved posts
Product detail pages
```

## Phase 3 — Data Quality

Goal: prevent messy duplicate cafe/product data.

Features:

```txt
Cafe suggestions
Product suggestions
Admin approval
Duplicate merge tools
Report post/comment
Verified cafe records
```

## Phase 4 — Cafe Business Tools

Goal: monetize through cafes.

Features:

```txt
Cafe profile claiming
Verified badge
Menu management
Basic analytics
Promos
Featured products
```

## Phase 5 — Ranking Expansion

Goal: make rankings more meaningful.

Features:

```txt
Weekly trending
City rankings
Category rankings
Budget rankings
Nearby rankings
Creator leaderboards
Cafe badges
```

## Phase 6 — Monetization

Goal: generate recurring revenue.

Features:

```txt
Cafe subscriptions
Sponsored placements
Analytics dashboard
Voucher campaigns
Product launch campaigns
Ranking badge kits
```

## Phase 7 — AI Features

Goal: improve discovery and cafe insights.

Features:

```txt
AI review summaries
AI sentiment analysis
Duplicate detection
Personalized recommendations
Cafe trend reports
Menu performance summaries
```
