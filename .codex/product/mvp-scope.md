# MVP Scope

## MVP Objective

Build the smallest useful version of CafeRank where users can post, uprank, comment, and discover cafe products.

## Must-Have Features

### User

- Sign up
- Log in
- Edit profile
- View own profile
- View other user profiles

### Posts

- Create post
- Upload product photo
- Select cafe
- Select product
- Add rating
- Add caption
- View feed
- View post detail

### Upranks

- Uprank a post
- Remove uprank
- Show uprank count
- Prevent duplicate upranks per user/post

### Comments

- Add comment
- View comments
- Show comment preview in feed

### Cafes

- View cafe profile
- Show cafe header
- Show user posts tab
- Show cafe menu tab

### Products

- View product details
- Show rating
- Show upranks
- Show related posts

### Rankings

- Show top products
- Filter by category
- Show trending this week

### Admin

- Approve suggested cafes
- Approve suggested products
- Hide bad posts
- Moderate comments

## Not MVP

Do not build these first:

```txt
Chat
DMs
Advanced cafe analytics
Cafe owner dashboard
Complex AI recommendations
Push notifications
Voucher redemption
Payments
Desktop-first dashboard
```

## MVP Build Order

```txt
1. Project setup
2. Auth
3. Database schema
4. Image upload
5. Create post
6. Feed
7. Upranks
8. Comments
9. Cafe profile
10. Product pages
11. Rankings
12. Admin moderation
```
