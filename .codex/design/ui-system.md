# UI System

## Visual Identity

CafeRank should feel:

```txt
Warm
Clean
Social
Photo-first
Cafe-inspired
Modern
Mobile-first
```

## Color Palette

```txt
Background: #FAF7F2
Surface: #FFFFFF
Primary Text: #241A16
Muted Text: #8B7E74
Primary Brown: #7B4B2A
Accent Caramel: #C98A4A
Border: #E8DED2
Rank Accent: #2F7D4F
```

## Typography

Recommended fonts:

```txt
Inter
Geist
Satoshi
Manrope
```

## Components

### PostCard

Used in the feed.

Must include:

```txt
User avatar
Username
Cafe name
Product name
Photo
Uprank button
Comment button
Save button
Rating
Caption
Comment preview
```

### UprankButton

States:

```txt
Default: ▲ Uprank
Active: ▲ Upranked
Compact: ▲ 284
```

### CafeHeader

Must include:

```txt
Cover photo
Logo
Name
Handle
Location
Post count
Rating
Rank
Follow button
Directions button
```

### ProductCard

Used in menu grid and product sections.

Must include:

```txt
Photo
Name
Price
Rating
Upranks
```

### RankingRow

Must include:

```txt
Rank number
Product thumbnail
Product name
Cafe name
Rating
Uprank count
```

### BottomNav

Must include:

```txt
Home
Explore
Create
Rankings
Profile
```

## Border Radius

Use soft rounded corners.

```txt
Cards: rounded-2xl
Buttons: rounded-full or rounded-xl
Images: rounded-xl
```

## Spacing

Use generous spacing.

```txt
Screen padding: 16px
Card gap: 12px-16px
Section gap: 24px
```

## Animation

Use subtle motion only.

Good:

```txt
Uprank pop
Tab transition
Button hover/tap scale
Skeleton loading
```

Avoid:

```txt
Heavy animations
Slow transitions
Distracting effects
```
